# Bem-vindo(a) ao meu perfil!

---

Sou graduando em Economia pela Universidade Estadual de Santa Cruz (UESC), com interesse nas áreas de Finanças e Ciência de Dados. Neste perfil, compartilho bases de dados, códigos e projetos desenvolvidos tanto em pesquisas acadêmicas quanto em aplicações voltadas ao ambiente corporativo. Meu objetivo é integrar teoria econômica, métodos quantitativos e ferramentas de análise de dados para transformar informações em conhecimento, apoiar a tomada de decisões e contribuir para a geração de valor nas organizações e para o avanço da produção científica.

Em relação às minhas competências técnicas, destaco:

* **Excel Avançado** — modelagem financeira, análise de dados e automação de rotinas administrativas (VBA).
* **Power BI** — desenvolvimento de dashboards e KPIs.
* **R** — econometria aplicada, séries temporais, análise multivariada e modelagem preditiva.
* **Python** — automação de processos, manipulação de dados e web scraping.
* **SQL** — consulta, manipulação e extração de informações em bancos de dados (Oracle, MySQL e SQL Server).
